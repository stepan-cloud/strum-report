# Отчёты водителей → Telegram → сверка в CRM

Водители после рейса заполняют Google Форму «Водители отчет». Скрипт Apps Script отправляет отчёт в Telegram,
а ссылка в сообщении открывает рейс в CRM с данными отчёта. На странице рейса появляется окно сверки
«CRM ↔ отчёт»: ФИО, километраж с допуском, точки, касса, комментарии водителя по точкам.

## Файлы

| Файл | Что это | Где работает |
|---|---|---|
| `telegram_report.gs` | Отправка ответа формы в Telegram | Apps Script формы (Редактор формы → ⋮ → Редактор скриптов) |
| `crm_report_panel.js` | Окно сверки на странице рейса | Подгружается загрузчиком с GitHub |
| `extension_loader.js` | Загрузчик окна сверки | Расширение «User JavaScript and CSS», сайт `strum-crm.onrender.com` |
| `driver_bot.gs` | Бот для водителей (копии отчётов, «маршрут завершён», переписка, очистка чатов) | Тот же проект Apps Script |

## Установка окна сверки на устройство

1. Поставить в Chrome расширение «User JavaScript and CSS».
2. Добавить правило для сайта `strum-crm.onrender.com` и вставить в поле JS содержимое `extension_loader.js`.
3. Сохранить. Дальше код окна берётся с GitHub сам — после правки `crm_report_panel.js` здесь
   он обновится на всех устройствах (GitHub может отдавать старую версию до ~5 минут).

## Apps Script

Токен бота и чат в `telegram_report.gs` не хранятся. Создайте в том же проекте Apps Script второй файл
(например «Настройки.gs», в репозиторий его не класть) и впишите:

```js
const TELEGRAM_TOKEN = '...'; // токен бота от @BotFather
const CHAT_ID = '...';        // куда слать сообщения
```

Вместо файла можно использовать Настройки проекта ⚙ → Свойства скрипта с теми же именами.

Функции: `setupTrigger()` — один раз, создаёт триггер на отправку формы; `testFakeAnswer()` — тестовое сообщение;
`testLastResponse()` — отправить последний настоящий ответ.

## Бот для водителей

Тот же бот шлёт отчёты в группу и копии — водителям в личку, пишет водителю «маршрут завершён» с итогом
после кнопки «Завершить» в окне сверки и пересылает переписку между группой и водителем. Водители
подключаются сами: «Старт» боту → фамилия и имя → заявка в группу с кнопками «Принять/Отклонить».
Команды в группе: `/водители` — список и удаление, `/водитель Фамилия [Имя] [текст]` — ответом на отчёт.

Установка:

1. Создать группу в Telegram, добавить бота и сделать его администратором. В файл настроек вписать
   `CHAT_ID` группы (супергруппа — ID вида `-100…`; узнать можно функцией `botShowChats()` — она покажет
   чаты из журнала событий).
2. `botSetup()` — один раз: создаёт таблицу-хранилище «Бот водителей — данные» на Диске (ссылка — в журнале
   выполнения). Листы: «Водители», «Сообщения», «Журнал».
3. `botStartPolling()` — включает опрос Telegram раз в минуту (`botStopPolling()` — выключает).
4. Веб-приложение — для «маршрут завершён» (ниже).

В личных чатах водителей бот раз в час удаляет все сообщения старше ~47 часов (и свои, и водителя —
Telegram разрешает удалять только моложе 48 ч), в группе ничего не удаляет. Строки «Сообщений» и «Журнала»
старше ~месяца стираются из таблицы.

### Веб-приложение бота («маршрут завершён»)

Окно сверки после «Завершить» просит бота написать водителю. Для этого проект развёрнут веб-приложением:
Apps Script → Развернуть → Новое развертывание → тип «Веб-приложение», запуск от моего имени, доступ «Все»
(развёртывание должен делать владелец проекта, иначе анонимный доступ не работает). Адрес `…/exec` вписать
в Настройки проекта ⚙ → Свойства скрипта: `BOT_WEBAPP_URL`. Отчёты, отправленные после этого, несут в ссылке
подпись рейса — без неё бот не пишет. После правки кода бота: Управление развертываниями → ✎ → Версия «Новая».
